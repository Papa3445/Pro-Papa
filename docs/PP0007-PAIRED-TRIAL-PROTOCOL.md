## Conduct an authentic paired trial

1. Freeze the exact Git commit and the identical **canonical objective and canonical inputs** for both conditions, with predeclared expectations, evaluation rubric and tool-permission policy. The original research case is bounded repository metadata; `novel` and the memo/planning cases lack detailed user context and may require a separately approved, *new* study with both arms restarted. Such a change cannot be retroactively substituted for the original case.
2. Invoke an **actual direct assistant** separately from the Pro-Papa reference host. Record the provider and version, configuration, time, interface, authorized tool list, number of interactions, and a durable provider-authentic record or a recording identified as **operator supplied, not independently provider verified**. Neither the `modelName` label nor a self-entered `sourceUri` authenticates a call.
3. Run the Pro-Papa host for the **identical underlying user objective**, through its supported interface and explicitly declared grants. Capture true code commit, handler status, all actual outputs, elapsed time boundaries, external tool calls, persist/receipt state and any follow-up turns. Keep refused requests as failed task completions, **not success** merely for safety.
4. Independently grade both full outputs blind where practical. Numeric results and repository URLs may be objectively checked; documents and open-ended planning require substantive human-quality review with grounded criteria, and source-backed research requires actual provenance review. Grade only outcomes genuinely observed. A withheld or ungraded artifact is `unknown`, not pass. Identify each grader and qualification/independence.
5. Collect **real corrections** per turn, elapsed milliseconds (including comparable startup/tool use), external call counts, and *provider-reported* token usage where it exists. Use `null` for unobservable cost; never back-compute nonexistent tokens from text length. Note unequal permissions, model context and refusal differences.
6. Preserve raw transcripts or private input in controlled private storage **outside the public repo**. Verify their file SHA-256, record actual provider/CI links and separately verify real private usage receipts where issued. Publish only non-sensitive, pinned summaries and checksums. A source link/hash provided by an operator is evidence metadata, not an authenticated provider receipt.
7. Report paired success fractions, per-case scores and overhead with uncertainty, and **do not assert improved general outcomes** unless original PP-0007 acceptance, a statistically defensible comparison and a new independent reviewer decision genuinely support it.
