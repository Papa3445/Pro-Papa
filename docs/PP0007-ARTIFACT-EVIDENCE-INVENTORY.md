## Privacy-safe proof policy for future original-byte review

Original PDFs, image pixels, regular/project screenshots, source ZIPs and user conversation content should stay in an authorized **private context**. A future independent reviewer with a real private file should log `SHA-256`, size/page count or archive entry list, visibly inspected pages/images, runnable checks and source identity in a **minimal privacy-safe summary**. Compare that measured hash to a previously reported one, and mark matches or differences. Source metadata by itself is insufficient; independently run code in a restricted environment and verify the output against predeclared mechanical criteria. No private materials or credentials in public issues, source fixtures, CI stdout or audit receipts.
